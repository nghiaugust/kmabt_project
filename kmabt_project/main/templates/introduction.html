About This Project

KMABT is developed as a student research project at the Academy of Cryptography Techniques (KMA), Vietnam's leading institution for cybersecurity education.

Project Focus Areas:

  • Bitcoin blockchain data analysis
  • Transaction pattern visualization
  • Anomaly detection research
  • User-friendly crypto investigation tools

This is a learning project aimed at understanding blockchain forensics and developing practical analysis tools.
